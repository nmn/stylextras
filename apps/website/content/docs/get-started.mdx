title: "Get started"
description: "Install the native-first Stylextras UI package and apply its StyleX themes."
---

Stylextras combines implementation and tokenized styling in each public component.
There is no unstyled primitive layer, provider, or theme root.

## Install

```sh
bun add @stylextras/ui @stylexjs/stylex react
```

`@stylextras/ui` exports TypeScript, JSX, and StyleX source. Configure your
application's existing compiler to transform the package together with local
source; there is no package CSS file or separate UI build step.

## Import components

Every stable component has a canonical subpath and there is no package barrel.

```tsx
import { Button } from "@stylextras/ui/button";
import { Field, FieldLabel } from "@stylextras/ui/field";
import { Select } from "@stylextras/ui/select";

export function Example() {
  return (
    <form>
      <Field>
        <FieldLabel htmlFor="priority">Priority</FieldLabel>
        <Select id="priority" name="priority" defaultValue="normal">
          <option value="normal">Normal</option>
          <option value="urgent">Urgent</option>
        </Select>
      </Field>
      <Button type="submit">Save</Button>
    </form>
  );
}
```

## Apply themes directly

Theme exports are ordinary StyleX style objects. Apply any combination to any
element; no provider, context, or client JavaScript is involved.

```tsx
import * as stylex from "@stylexjs/stylex";
import type { ReactNode } from "react";
import { neutralTheme } from "@stylextras/ui/color-themes/neutral";
import { zincTheme } from "@stylextras/ui/color-themes/zinc";
import { roundedTheme } from "@stylextras/ui/radius-themes/rounded";
import { compactTheme } from "@stylextras/ui/spacing-themes/compact";

export function ThemeBoundary({ children }: { children: ReactNode }) {
  return (
    <section
      {...stylex.props(
        neutralTheme,
        zincTheme,
        compactTheme,
        roundedTheme,
      )}
    >
      {children}
    </section>
  );
}
```

The independent variable groups are colors, spacing, radius, stroke,
typography, elevation, blur, and motion. Each group keeps its themeable core and
same-set derived values together. Named subpaths include only the imported
theme; importing a family root such as `@stylextras/ui/color-themes` opts into
the complete catalog for theme pickers.

Accent colors are compact overrides. Apply `neutralTheme` before one when you
compose color themes directly; this resets every color variable at nested theme
boundaries. Named style presets include the reset automatically.
