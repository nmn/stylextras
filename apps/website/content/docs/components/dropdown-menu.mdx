## Anatomy

- `DropdownMenu` — Styled `<div>`.
- `DropdownMenuContent` — Styled `<div>`.
- `DropdownMenuGroup` — `<div role="group">` named by a menu label.
- `DropdownMenuItem` — Styled `<button>`.
- `DropdownMenuLabel` — Styled `<div>`.
- `DropdownMenuSeparator` — Styled `<hr>`.
- `DropdownMenuShortcut` — Styled `<kbd>`.
- `DropdownMenuTrigger` — Styled `<button>`.

## Accessibility and browser behavior

Each part renders and styles the native element named above. The API reference states the exact React or inherited prop base, including whether `ref` is accepted, every omitted native prop, and every component-applied default. Any native prop not named in `Omit` remains accepted, including standard ARIA/data attributes and event handlers. `sx` is composed last.

The trigger supports <kbd>Enter</kbd>, <kbd>Space</kbd>, <kbd>ArrowDown</kbd>, and <kbd>ArrowUp</kbd>. The menu uses `focusgroup` for wrapped arrow-key navigation plus <kbd>Home</kbd> and <kbd>End</kbd>; a feature-detected polyfill supplies that behavior where necessary. Printable keys move focus by item label, <kbd>Escape</kbd> closes the menu and restores trigger focus, and <kbd>Tab</kbd> closes it after focus moves out.

Disabled items use `aria-disabled` so they remain discoverable by arrow-key navigation while activation is suppressed. `aria-controls`, `aria-expanded`, and the menu's accessible name are synchronized with the native popover state.

Wrap related items and their visible label in `DropdownMenuGroup`, and connect
the group to `DropdownMenuLabel` with `aria-labelledby`.

## API reference

### DropdownMenu

`DropdownMenuProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "style">`. The props below complete `DropdownMenuProps`.

- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### DropdownMenuContent

`DropdownMenuContentProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "popover" | "role" | "style">`. The props below complete `DropdownMenuContentProps`.

- `placement` — `DropdownMenuPlacement`. Sets the preferred anchored edge; the browser may flip it to remain visible. Default: `'bottom'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### DropdownMenuItem

`DropdownMenuItemProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"button">, "className" | "role" | "style">`. The props below complete `DropdownMenuItemProps`.

- `closeOnSelect` — `boolean`. Closes the owning menu after this item activates when enabled. Default: `true`.
- `disabled` — `boolean`. Default: `false`. Rendered as `aria-disabled` so the item remains focusable.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
- `type` — `DropdownMenuItemProps["type"]`. Sets the underlying element's native control type. Default: `'button'`.

### DropdownMenuGroup

`DropdownMenuGroupProps` extends native `div` props with a forwarded ref and `sx`.

- `aria-labelledby` — Required ID reference to the group's `DropdownMenuLabel`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### DropdownMenuTrigger

`DropdownMenuTriggerProps`

Complete native/inherited prop base: `Omit<ButtonProps, "popoverTarget" | "popoverTargetAction">`. The props below complete `DropdownMenuTriggerProps`.

- `aria-haspopup` — `DropdownMenuTriggerProps["aria-haspopup"]`. Announces the kind of popup controlled by the trigger. Default: `'menu'`.
- `aria-controls` — `DropdownMenuTriggerProps["aria-controls"]`. Identifies the menu popover controlled by the trigger. Default: `target`.
- `aria-expanded` — `DropdownMenuTriggerProps["aria-expanded"]`. Default: `false`; synchronized with the popover's open state.
- `id` — `string`. Stable trigger ID used by the menu's accessible-name relationship. Default: `` `${target}-trigger` ``.
- `size` — `ButtonSize`. Controls visual dimensions and, for interactive components, the target size. Default: `'md'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
- `target` — `string`. ID of the element controlled by this trigger. Required.
- `type` — `DropdownMenuTriggerProps["type"]`. Sets the underlying element's native control type. Default: `'button'`.
- `variant` — `ButtonVariant`. Selects the built-in visual treatment. Default: `'outline'`.
