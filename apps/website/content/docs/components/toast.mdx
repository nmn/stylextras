## Accessibility and browser behavior

Each part renders and styles the native element named above. The API reference states the exact React or inherited prop base, including whether `ref` is accepted, every omitted native prop, and every component-applied default. Any native prop not named in `Omit` remains accepted, including standard ARIA/data attributes and event handlers. `sx` is composed last.

The queue uses one polite and one assertive text-only announcer owner, keeping interactive controls outside live regions. Primitive string/number titles and descriptions are extracted safely; `announcement` is required whenever visual content contains React elements. Only visible FIFO records start timers or announce, so queued actions never become audible before they are reachable. Visual urgency is independent from announcement priority. Timers pause while the page is hidden and while users hover or focus notifications; actionable notifications remain until dismissed unless a duration is supplied.

## API reference

### Toast

`ToastProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"li">, "className" | "role" | "style">`. The props below complete `ToastProps`.

- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
- `announcement` — Plain text required when `priority` is `"polite"` or `"assertive"`.
- `priority` — `"polite" | "assertive" | "off"`. Controls whether and how this static toast content is announced. Default: `'off'`.
- `variant` — `"default" | "success" | "danger"`. Selects the built-in visual treatment. Default: `'default'`.

### toast

`toast(options)` queues a visual toast and returns `{ id, dismiss }`.

- `announcement` — `string`. Required plain live-region text for rich `title` or `description` content.
- `description` — `ReactNode`. Secondary toast content rendered beneath the title.
- `duration` — `number`. Defaults to `4000`, or `0` when an action is present.
- `id` — `string`. Stable DOM identifier used by related controls and ARIA references.
- `priority` — `"polite" | "assertive"`. Selects the live-region urgency for an enqueued toast. Default: `'polite'`.
- `title` — Primitive text, or rich `ReactNode` when `announcement` is supplied. Required.
- `variant` — `"default" | "success" | "danger"`. Selects the built-in visual treatment. Default: `'default'`.

### Toaster

`ToasterProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"ol">, "children" | "className" | "style">`. The props below complete `ToasterProps`.

- `aria-label` — `ToasterProps["aria-label"]`. Accessible name for the ordered notification region. Default: `'Notifications'`.
- `getDismissLabel` — `(toast: ToastDismissContext) => string`. Defaults to a contextual label derived from the title or announcement.
- `limit` — `number`. Maximum number of simultaneously reachable toast records. Default: `3`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
