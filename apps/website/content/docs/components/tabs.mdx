## Accessibility and browser behavior

Each part renders and styles the native element named above. The API reference states the exact React or inherited prop base, including whether `ref` is accepted, every omitted native prop, and every component-applied default. Any native prop not named in `Omit` remains accepted, including standard ARIA/data attributes and event handlers. `sx` is composed last.

This component implements the tab keyboard pattern directly, including RTL horizontal arrows, without loading the focusgroup bridge. Every tablist requires an accessible name. Generated IDs, relationships, roles, orientation, selection, visibility, and tab stops are component-owned and cannot be overridden by consumer props. If the selected value points to a disabled tab, the first enabled tab becomes the roving tab stop. Use manual activation when panel content is deferred or otherwise not instantly available.

Unprevented pointer activation always selects a tab, in both automatic and
manual modes. Values must be unique across triggers and panels; duplicates
produce a development warning. Panels default to `tabIndex={0}` so their content
is reachable as one keyboard stop, and can opt out with `tabIndex={-1}` when
their own contents already provide an appropriate focus target.

## API reference

### Tabs

`TabsProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "defaultValue" | "style">`. The props below complete `TabsProps`.

- `activationMode` — `"manual" | "automatic"`. Chooses whether focus alone or explicit activation selects a tab. Default: `'automatic'`.
- `defaultValue` — `string`. Initial value for uncontrolled usage. Default: `''`.
- `onValueChange` — `(value: string) => void`. Called when user interaction requests a new value.
- `orientation` — `"vertical" | "horizontal"`. Controls the layout axis and, where applicable, Arrow-key behavior. Default: `'horizontal'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
- `value` — `string`. Current controlled value; pair it with `onValueChange`.

### TabsContent

`TabsContentProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "aria-labelledby" | "className" | "hidden" | "id" | "role" | "style">`. The props below complete `TabsContentProps`.

- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
- `tabIndex` — `0 | -1`. Includes the active panel in the Tab order or opts it out. Default: `0`.
- `value` — `string`. Stable identifier or value used by the selection model and by form submission when applicable. Required.

### TabsList

`TabsListProps`

Complete native/inherited prop base: native div props with component-owned `role`, `aria-orientation`, and styles. `aria-label` or `aria-labelledby` is required.

- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### TabsTrigger

`TabsTriggerProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"button">, "aria-controls" | "aria-selected" | "className" | "id" | "role" | "style" | "tabIndex" | "type" | "value">`. The props below complete `TabsTriggerProps`.

- `disabled` — `boolean`. Default: `false`; disabled tabs are excluded from Arrow-key navigation and cannot become selected.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
- `value` — `string`. Stable identifier or value used by the selection model and by form submission when applicable. Required.
