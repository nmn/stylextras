## Usage

```tsx
import {
  TableOfContents,
  TableOfContentsItem,
  TableOfContentsLink,
  TableOfContentsList,
  TableOfContentsTitle,
} from "@stylextras/ui/table-of-contents";

export function ArticleOutline() {
  return (
    <TableOfContents aria-labelledby="outline-title">
      <TableOfContentsTitle id="outline-title">
        On this page
      </TableOfContentsTitle>
      <TableOfContentsList>
        <TableOfContentsItem>
          <TableOfContentsLink active href="#overview">
            Overview
          </TableOfContentsLink>
          <TableOfContentsList>
            <TableOfContentsItem>
              <TableOfContentsLink href="#examples">
                Examples
              </TableOfContentsLink>
            </TableOfContentsItem>
          </TableOfContentsList>
        </TableOfContentsItem>
      </TableOfContentsList>
    </TableOfContents>
  );
}
```

## Anatomy

- `TableOfContents` — Styled `<nav>`.
- `TableOfContentsTitle` — Polymorphic heading; defaults to `<h2>`.
- `TableOfContentsList` — Styled `<ol>`.
- `TableOfContentsItem` — Styled `<li>`.
- `TableOfContentsLink` — Styled hash `<a>`.

## Accessibility and browser behavior

The root requires an accessible name. A visible title can provide it through
`aria-labelledby`. Represent heading depth by nesting `TableOfContentsList`
inside its parent `TableOfContentsItem`; visual indentation alone does not expose
the document outline. Active links emit `aria-current="location"`, and the
consumer remains responsible for calculating the active heading.

## API reference

### TableOfContents

`TableOfContentsProps`

Complete native/inherited prop base is native `nav` props with component-owned styling and one required accessible name.

- `aria-label` — Direct navigation-landmark name; required unless `aria-labelledby` is provided.
- `aria-labelledby` — ID of visible text naming the landmark; required unless `aria-label` is provided.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### TableOfContentsTitle

`TableOfContentsTitleProps`

Complete native/inherited prop base is the selected heading element's native props.

- `as` — `'h2' | 'h3' | 'h4' | 'h5' | 'h6'`. Default: `'h2'`; match the page outline.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### TableOfContentsList

`TableOfContentsListProps`

Complete native/inherited prop base is native `ol` props with `role="list"` restored by the component.

- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### TableOfContentsItem

`TableOfContentsItemProps`

Complete native/inherited prop base is native `li` props.

- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### TableOfContentsLink

`TableOfContentsLinkProps`

Complete native/inherited prop base is native anchor props with `href` and `aria-current` managed explicitly.

- `active` — `boolean`. Marks this link as the current document location with `aria-current`. Default: `false`.
- `aria-current` — Native `aria-current` value used when `active` is false.
- `href` — `string`. Required in-page hash destination.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
