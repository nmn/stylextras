## Anatomy

- `PopoverClose` — Styled `<button>`.
- `PopoverTrigger` — Styled `<button>`.

## Accessibility and browser behavior

Each part renders and styles the native element named above. The API reference states the exact React or inherited prop base, including whether `ref` is accepted, every omitted native prop, and every component-applied default. Any native prop not named in `Omit` remains accepted, including standard ARIA/data attributes and event handlers. `sx` is composed last.

This component starts with semantic HTML and enhances it with newer browser APIs when they are available. Without anchor positioning support, the component remains usable with a simpler non-anchored layout.

## API reference

### Popover

`PopoverProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "popover" | "style">`. The props below complete `PopoverProps`.

- `behavior` — `"auto" | "manual" | "hint"`. Selects native Popover light-dismiss and stacking behavior. Default: `'auto'`.
- `placement` — `PopoverPlacement`. Sets the preferred anchored edge; the browser may flip it to remain visible. Default: `'bottom'`.
- `size` — `PopoverSize`. Controls visual dimensions and, for interactive components, the target size. Default: `'md'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### PopoverClose

`PopoverCloseProps`

Complete native/inherited prop base: `Omit<PopoverTriggerProps, "action">`. The props below complete `PopoverCloseProps`.

- `size` — `ButtonSize`. Controls visual dimensions and, for interactive components, the target size. Default: `'md'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
- `target` — `string`. ID of the element controlled by this trigger. Required.
- `type` — `PopoverCloseProps["type"]`. Sets the underlying element's native control type. Default: `'button'`.
- `variant` — `ButtonVariant`. Selects the built-in visual treatment. Default: `'outline'`.

### PopoverTrigger

`PopoverTriggerProps`

Complete native/inherited prop base: `Omit<ButtonProps, "popoverTarget" | "popoverTargetAction">`. The props below complete `PopoverTriggerProps`.

- `action` — `"show" | "hide" | "toggle"`. Native action the invoker performs on its popover target. Default: `'toggle'`.
- `size` — `ButtonSize`. Controls visual dimensions and, for interactive components, the target size. Default: `'md'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
- `target` — `string`. ID of the element controlled by this trigger. Required.
- `type` — `PopoverTriggerProps["type"]`. Sets the underlying element's native control type. Default: `'button'`.
- `variant` — `ButtonVariant`. Selects the built-in visual treatment. Default: `'outline'`.
