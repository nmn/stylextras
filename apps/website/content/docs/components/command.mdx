## Anatomy

- `Command` — Styled `<dialog>`.
- `CommandEmpty` — Styled `<div>`.
- `CommandInput` — Styled `<input>`.
- `CommandItem` — Non-tabbable `<div role="option">`.
- `CommandList` — Styled `<div>`.
- `CommandStatus` — Visually hidden polite result announcement.
- `CommandTrigger` — Styled `<button>`.

## Accessibility and browser behavior

Each part renders and styles the native element named above. The API reference states the exact React or inherited prop base, including whether `ref` is accepted, every omitted native prop, and every component-applied default. Any native prop not named in `Omit` remains accepted, including standard ARIA/data attributes and event handlers. `sx` is composed last.

The input owns focus and controls the DOM-ordered option collection through
`aria-activedescendant`; options do not enter the ordinary Tab order. Arrow keys,
Home, End, and Enter operate the active option and scroll it into view. Keep only
`CommandItem` options inside `CommandList`; render `CommandEmpty` and
`CommandStatus` as siblings outside the listbox. Duplicate values produce a
development warning without changing ID-based active identity.

## API reference

### Command

`CommandProps`

Complete native/inherited prop base: native dialog props with component-owned styles. `aria-label` or `aria-labelledby` is required.

- `onValueChange` — `(value: string) => void`. Called when user interaction requests a new value.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### CommandEmpty

`CommandEmptyProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "style">`. The props below complete `CommandEmptyProps`.

- `children` — `CommandEmptyProps["children"]`. Content shown when no command items match the query. Default: `'No results.'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### CommandInput

`CommandInputProps`

Complete native/inherited prop base omits the component-owned
active-descendant, listbox, expanded state, role, value, and input type.
`aria-label` or `aria-labelledby` is required so the combobox has an accessible
name.

- `aria-expanded` — `CommandInputProps["aria-expanded"]`. Announces that the command listbox is visible while its dialog is mounted. Default: `'true'`.
- `autoComplete` — `CommandInputProps["autoComplete"]`. Provides the native browser autofill hint. Default: `'off'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
- `type` — `'text' | 'search'`. Sets the underlying element's native control type. Default: `'search'`.

### CommandItem

`CommandItemProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "aria-disabled" | "aria-selected" | "className" | "onSelect" | "role" | "style" | "tabIndex">`. The props below complete `CommandItemProps`.

- `disabled` — `CommandItemProps["disabled"]`. Keeps the item discoverable but excludes it from activation and keyboard selection. Default: `false`.
- `hidden` — `boolean`. Default: `false`; author-hidden items remain excluded even when the text filter matches.
- `keywords` — `string`. Additional searchable terms that are not rendered as the item label. Default: `''`.
- `onSelect` — `(value: string) => void`. Called with the item value when keyboard or pointer activation selects it.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
- `value` — `string`. Stable identifier or value used by the selection model and by form submission when applicable. Required.

### CommandList

`CommandListProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "role" | "style">`. The props below complete `CommandListProps`.

- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### CommandTrigger

`CommandTriggerProps`

Complete native/inherited prop base: `ButtonProps`. The props below complete `CommandTriggerProps`.

- `size` — `ButtonSize`. Controls visual dimensions and, for interactive components, the target size. Default: `'md'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
- `target` — `string`. ID of the element controlled by this trigger. Required.
- `type` — `CommandTriggerProps["type"]`. Sets the underlying element's native control type. Default: `'button'`.
- `variant` — `ButtonVariant`. Selects the built-in visual treatment. Default: `'primary'`.

### CommandStatus

- `children` — `ReactNode | ((count: number) => ReactNode)`. Polite status content; a callback receives the current result count. Required.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
