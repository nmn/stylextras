### Example code

```tsx
import { Alert, AlertDescription, AlertTitle } from './index';

export default function Example() {
  return (
    <>
      {(['default', 'info', 'success', 'warning', 'danger'] as const).map(
        (variant) => (
          <Alert key={variant} variant={variant}>
            <AlertTitle>
              {variant === 'default' ? 'Update available' : variant}
            </AlertTitle>
            <AlertDescription>
              A concise message with semantic status treatment.
            </AlertDescription>
          </Alert>
        ),
      )}
    </>
  );
}
```

## Anatomy

- `Alert` — Styled `<div>`.
- `AlertDescription` — Styled `<div>`.
- `AlertTitle` — Polymorphic heading; defaults to `<h3>`.

## Accessibility and browser behavior

`Alert` is static by default, so content present at page load is not announced as
though it just changed. Add `role="status"` for a polite update inserted after a
user action, or `role="alert"` only for a time-sensitive assertive update. Do not
put interactive descendants inside either live-region variant.

## API reference

### Alert

`AlertProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "style">`. The props below complete `AlertProps`.

- `role` — Native `div` role. No default; use `status` or `alert` explicitly for dynamic updates.
- `sx` — `stylex.StyleXStyles`.
- `variant` — `AlertVariant`. Default: `'default'`.

### AlertDescription

`AlertDescriptionProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "style">`. The props below complete `AlertDescriptionProps`.

- `sx` — `stylex.StyleXStyles`.

### AlertTitle

`AlertTitleProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<T>, "className" | "style">`. The props below complete `AlertTitleProps`.

- `as` — Heading element type. Default: `'h3'`.
- `sx` — `stylex.StyleXStyles`.
