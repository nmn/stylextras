### Example code

```tsx
import { Input } from '../input';
import { Field, FieldDescription, FieldError, FieldLabel } from './index';

export default function Example() {
  return (
    <>
      <Field>
        <FieldLabel htmlFor="field-email">Email</FieldLabel>
        <Input
          id="field-email"
          aria-describedby="field-email-description"
          type="email"
          placeholder="you@example.com"
        />
        <FieldDescription id="field-email-description">
          Used only for account notifications.
        </FieldDescription>
      </Field>
      <Field>
        <FieldLabel htmlFor="field-handle">Handle</FieldLabel>
        <Input
          id="field-handle"
          aria-describedby="field-handle-error"
          aria-errormessage="field-handle-error"
          aria-invalid="true"
          defaultValue="two words"
        />
        <FieldError id="field-handle-error">
          Use letters, numbers, and hyphens only.
        </FieldError>
      </Field>
    </>
  );
}
```

## Anatomy

- `Field` — Styled `<div>`.
- `FieldDescription` — Styled `<p>`.
- `FieldError` — Styled `<p>`.
- `FieldLabel` — Styled `<label>`.

## Accessibility and browser behavior

Associate `FieldLabel` with its control through matching `htmlFor` and `id`.
Reference help text with `aria-describedby`. When the control is invalid, set
`aria-invalid="true"` and reference `FieldError` with `aria-errormessage`.
`FieldError` is static by default; opt into `role="alert"` only when a newly
inserted error must be announced immediately.

## API reference

### Field

`FieldProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "style">`. The props below complete `FieldProps`.

- `sx` — `stylex.StyleXStyles`.

### FieldDescription

`FieldDescriptionProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"p">, "className" | "style">`. The props below complete `FieldDescriptionProps`.

- `sx` — `stylex.StyleXStyles`.

### FieldError

`FieldErrorProps`

Complete native/inherited prop base: `FieldDescriptionProps`. The props below complete `FieldErrorProps`.

- `role` — Native paragraph role. No default; live announcement is caller opt-in.
- `sx` — `stylex.StyleXStyles`.

### FieldLabel

`FieldLabelProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"label">, "className" | "style">`. The props below complete `FieldLabelProps`.

- `sx` — `stylex.StyleXStyles`.
