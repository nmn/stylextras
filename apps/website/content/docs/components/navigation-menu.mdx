## Anatomy

- `NavigationMenu` — Styled `<nav>`.
- `NavigationMenuContent` — Styled `<div>`.
- `NavigationMenuItem` — Styled `<li>`.
- `NavigationMenuLink` — Styled `<a>`.
- `NavigationMenuList` — Styled `<ul role="list">`.
- `NavigationMenuTrigger` — Styled `<button>`.

## Accessibility and browser behavior

Each part renders and styles the native element named above. The API reference states the exact React or inherited prop base, including whether `ref` is accepted, every omitted native prop, and every component-applied default. Any native prop not named in `Omit` remains accepted, including standard ARIA/data attributes and event handlers. `sx` is composed last.

Name the navigation landmark and use real destinations for every
`NavigationMenuLink`. Same-page link activation dismisses an open menu panel
unless the consumer prevents the click. Without anchor positioning support, the
popover remains usable with simpler placement.

## API reference

### NavigationMenu

`NavigationMenuProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"nav">, "aria-label" | "aria-labelledby" | "className" | "style">` plus one required accessible name.

- `aria-label` or `aria-labelledby` — Required navigation-landmark name.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### NavigationMenuContent

`NavigationMenuContentProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "popover" | "style">`. The props below complete `NavigationMenuContentProps`.

- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### NavigationMenuItem

`NavigationMenuItemProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"li">, "className" | "style">`. The props below complete `NavigationMenuItemProps`.

- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### NavigationMenuLink

`NavigationMenuLinkProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"a">, "className" | "style">`. The props below complete `NavigationMenuLinkProps`.

- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### NavigationMenuList

`NavigationMenuListProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"ul">, "className" | "role" | "style">`; `role="list"` is restored explicitly.

- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### NavigationMenuTrigger

`NavigationMenuTriggerProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"button">, "className" | "style">`. The props below complete `NavigationMenuTriggerProps`.

- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
- `target` — `string`. ID of the element controlled by this trigger. Required.
- `type` — `NavigationMenuTriggerProps["type"]`. Sets the underlying element's native control type. Default: `'button'`.
