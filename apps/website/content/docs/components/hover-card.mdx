## Accessibility and browser behavior

Each part renders and styles the native element named above. The API reference states the exact React or inherited prop base, including whether `ref` is accepted, every omitted native prop, and every component-applied default. Any native prop not named in `Omit` remains accepted, including standard ARIA/data attributes and event handlers. `sx` is composed last.

This component starts with semantic HTML and enhances it with newer browser APIs when they are available. When the relevant browser interaction API is unavailable, the package loads a narrowly scoped, feature-detected bridge for that behavior.

## API reference

### HoverCard

`HoverCardProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "popover" | "style">`. The props below complete `HoverCardProps`.

- `placement` — `HoverCardPlacement`. Sets the preferred anchored edge; the browser may flip it to remain visible. Default: `'bottom'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### HoverCardTrigger

`HoverCardTriggerProps`

Complete native/inherited prop base: `ButtonProps`. The props below complete `HoverCardTriggerProps`.

- `hideDelay` — `number`. Milliseconds to wait before hiding after interest leaves the trigger and surface.
- `popoverTargetAction` — `HoverCardTriggerProps["popoverTargetAction"]`. Native action performed on the referenced popover. Default: `'toggle'`.
- `showDelay` — `number`. Milliseconds to wait before showing after hover or focus interest begins.
- `size` — `ButtonSize`. Controls visual dimensions and, for interactive components, the target size. Default: `'md'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
- `target` — `string`. ID of the element controlled by this trigger. Required.
- `type` — `HoverCardTriggerProps["type"]`. Sets the underlying element's native control type. Default: `'button'`.
- `variant` — `ButtonVariant`. Selects the built-in visual treatment. Default: `'link'`.
