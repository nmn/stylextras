## Anatomy

- `Carousel` — Named scrollable `<div>` with native previous and next `<button>` controls.
- `CarouselItem` — Named `<div role="group" aria-roledescription="slide">`.

## Accessibility and browser behavior

Each part renders and styles the native element named above. The API reference states the exact React or inherited prop base, including whether `ref` is accepted, every omitted native prop, and every component-applied default. Any native prop not named in `Omit` remains accepted, including standard ARIA/data attributes and event handlers. `sx` is composed last.

The root and every slide require accessible names. Previous and next actions
are real `<button>` elements associated with the scroll region through
`aria-controls`; each localized label is rendered as text in a visually hidden
`<span>`. Without client enhancement, the focusable native scroll region still
supports scrolling and scroll snapping. Root roles are restricted to `region`
or `group`, and slide roles to `group`.

## API reference

### Carousel

`CarouselProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "aria-label" | "aria-labelledby" | "className" | "role" | "style">` plus one required accessible name.

- `role` — `CarouselProps["role"]`. Landmark role applied to the scroll viewport. Default: `'region'`.
- `aria-roledescription` — Localizable role description. Default: `'carousel'`.
- `previousButtonLabel` — `string`. Accessible name for the previous-slide control. Default: `'Previous slide'`.
- `nextButtonLabel` — `string`. Accessible name for the next-slide control. Default: `'Next slide'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
- `tabIndex` — `CarouselProps["tabIndex"]`. Makes the native scroll viewport reachable by keyboard. Default: `0`.

### CarouselItem

`CarouselItemProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "aria-label" | "aria-labelledby" | "className" | "role" | "style">` plus one required accessible name.

- `aria-label` or `aria-labelledby` — Required slide name.
- `aria-roledescription` — Localizable role description. Default: `'slide'`.
- `role` — `'group'`. Groups each slide within the named carousel region. Default: `'group'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
