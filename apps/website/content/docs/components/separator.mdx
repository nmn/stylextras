## API reference

### Separator

`SeparatorProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"hr">, "className" | "style">`. The props below complete `SeparatorProps`.

- `decorative` — `boolean`. Removes separator semantics when the line is purely visual. Default: `true`.
- `emphasis` — `"strong" | "subtle"`. Selects the separator's border contrast. Default: `'subtle'`.
- `orientation` — `"vertical" | "horizontal"`. Controls the layout axis and, where applicable, Arrow-key behavior. Default: `'horizontal'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
