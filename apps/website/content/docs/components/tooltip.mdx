- `TooltipTrigger` — Styled `<button>`.

## Accessibility and browser behavior

Each part renders and styles the native element named above. The API reference states the exact React or inherited prop base, including whether `ref` is accepted, every omitted native prop, and every component-applied default. Any native prop not named in `Omit` remains accepted, including standard ARIA/data attributes and event handlers. `sx` is composed last.

The trigger is associated with the tooltip through `aria-describedby`. Tooltip
content is hoverable, so a pointer can move from the trigger onto the hint
without dismissing it, and Escape closes it. The native path uses
`popover="hint"` and `interestfor`; a feature-detected fallback supplies the same
focus/hover persistence when needed. Tooltip content must remain
non-interactive—put links, buttons, and form controls in a `HoverCard`, popover,
or dialog. Development builds warn when interactive semantics, focusability, or
detectable activation handlers are added, including descendants inserted after
mount.

## API reference

### Tooltip

`TooltipProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "popover" | "role" | "style">`. The component owns `role="tooltip"` and `popover="hint"`.

- `placement` — `TooltipPlacement`. Sets the preferred anchored edge; the browser may flip it to remain visible. Default: `'top'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### TooltipTrigger

`TooltipTriggerProps`

Complete native/inherited prop base: `ButtonProps`. The props below complete `TooltipTriggerProps`.

- `hideDelay` — `number`. Milliseconds to wait before hiding after interest leaves the trigger and surface.
- `popoverTargetAction` — `TooltipTriggerProps["popoverTargetAction"]`. Native action performed on the referenced popover. Default: `'toggle'`.
- `showDelay` — `number`. Milliseconds to wait before showing after hover or focus interest begins.
- `size` — `ButtonSize`. Controls visual dimensions and, for interactive components, the target size. Default: `'md'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
- `target` — `string`. ID of the element controlled by this trigger. Required.
- `type` — `TooltipTriggerProps["type"]`. Sets the underlying element's native control type. Default: `'button'`.
- `variant` — `ButtonVariant`. Selects the built-in visual treatment. Default: `'ghost'`.
