## Anatomy

- `Dialog` — Styled `<dialog>`.
- `DialogBody` — Styled `<div>`.
- `DialogClose` — Styled `<button>`.
- `DialogCommandBridge` — Optional client bridge that renders no DOM.
- `DialogDescription` — Styled `<p>`.
- `DialogFooter` — Styled `<footer>`.
- `DialogHeader` — Styled `<header>`.
- `DialogTitle` — Styled `<h2>`.
- `DialogTrigger` — Styled `<button>`.

## Accessibility and browser behavior

Each part renders and styles the native element named above. The API reference states the exact React or inherited prop base, including whether `ref` is accepted, every omitted native prop, and every component-applied default. Any native prop not named in `Omit` remains accepted, including standard ARIA/data attributes and event handlers. `sx` is composed last.

The base entry is server-renderable and uses native `command`/`commandfor`
invokers with no client JavaScript. Associate a title and any concise
description through `aria-labelledby` and `aria-describedby`. Add
`DialogCommandBridge` for older browsers; it feature-detects native support and
loads the fallback only when needed. `DialogClient` includes that bridge when it
has an `id` and also supplies cancelable backdrop-pointer `closedby="any"`
parity in engines that do not implement it.

`DialogCommandBridge` renders no DOM. Its `target` must match the dialog `id` and the associated `DialogTrigger`/`DialogClose` targets.

When a `DialogClient` contains nested popovers, their open order is tracked so
Escape closes the actual topmost child before it requests that the dialog close.

## API reference

### Dialog

`DialogProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"dialog">, "aria-label" | "aria-labelledby" | "className" | "style">` plus one required accessible name.

- `aria-label` or `aria-labelledby` — Required accessible dialog name.
- `closedBy` — `"none" | "any" | "closerequest"`. Controls which browser dismissal requests may close the dialog. Default: `'any'`.
- `size` — `DialogSize`. Controls visual dimensions and, for interactive components, the target size. Default: `'md'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### DialogBody

`DialogBodyProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "style">`. The props below complete `DialogBodyProps`.

- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### DialogClient

`DialogClientProps`

Optional client adapter for controlled or initially open dialogs. It accepts `DialogProps` except the native `open` prop and automatically installs `DialogCommandBridge` when `id` is provided.

- `defaultOpen` — `boolean`. Initial open state for uncontrolled usage. Default: `false`.
- `onOpenChange` — `(open: boolean) => void`. Called whenever native dialog events reconcile a new open state.
- `open` — `boolean`. Controlled open state; pair it with `onOpenChange`.
- Backdrop requests are cancelable through `onCancel`; prevent the event to keep the dialog open.

### DialogCommandBridge

`DialogCommandBridgeProps`

- `target` — `string`. Required. Must match the dialog `id`; the legacy fallback is imported only when native invoker commands are absent.

### DialogClose

`DialogCloseProps`

Complete native/inherited prop base: `ButtonProps`. The props below complete `DialogCloseProps`.

- `size` — `ButtonSize`. Controls visual dimensions and, for interactive components, the target size. Default: `'md'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
- `target` — `string`. ID of the element controlled by this trigger. Required.
- `type` — `DialogCloseProps["type"]`. Sets the underlying element's native control type. Default: `'button'`.
- `variant` — `ButtonVariant`. Selects the built-in visual treatment. Default: `'outline'`.
