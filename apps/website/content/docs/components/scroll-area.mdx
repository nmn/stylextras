Each part renders and styles the native element named above. The API reference states the exact React or inherited prop base, including whether `ref` is accepted, every omitted native prop, and every component-applied default. Any native prop not named in `Omit` remains accepted, including standard ARIA/data attributes and event handlers. `sx` is composed last.

## API reference

### ScrollArea

`ScrollAreaProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "aria-label" | "aria-labelledby" | "className" | "style" | "tabIndex">`. The props below complete `ScrollAreaProps`.

- `aria-label` — `string`. Required when `tabIndex={0}` unless `aria-labelledby` is provided.
- `aria-labelledby` — `string`. Required when `tabIndex={0}` unless `aria-label` is provided.
- `scrollbar` — `'stable' | 'overlay'`. Chooses reserved-gutter scrollbars or compact overlay scrollbars. Default: `'stable'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
- `tabIndex` — `-1 | 0`. No default; `0` makes the overflow region keyboard-focusable and requires an accessible name.
