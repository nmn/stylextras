Each part renders and styles the native element named above. The API reference states the exact React or inherited prop base, including whether `ref` is accepted, every omitted native prop, and every component-applied default. ## API reference

### Typography

`TypographyProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<T>, "className" | "style">`. The props below complete `TypographyProps`.

- `as` — `T`. Polymorphic element type used for the rendered text node.
- `mono` — `boolean`. Switches from the sans token to the monospace font token. Default: `false`.
- `scale` — `TypographyScale`. Selects the tokenized font size, weight, and line-height treatment. Default: `'body'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
- `tone` — `TypographyTone`. Selects the semantic foreground-color treatment. Default: `'default'`.
