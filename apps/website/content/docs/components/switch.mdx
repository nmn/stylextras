### Example code

```tsx
import * as stylex from '@stylexjs/stylex';
import { Label } from '../label';
import { spacing } from '../tokens/spacing.stylex';
import { Switch } from './index';

export default function Example() {
  return (
    <fieldset>
      <legend>Profile preferences</legend>
      <Label sx={styles.option}>
        <Switch defaultChecked /> Notifications
      </Label>
      <Label sx={styles.option}>
        <Switch /> Public profile
      </Label>
      <Label sx={styles.option}>
        <Switch controlSize="sm" /> Compact mode
      </Label>
    </fieldset>
  );
}

const styles = stylex.create({
  option: { alignItems: 'center', display: 'flex', gap: spacing.sm },
});
```

## Accessibility and browser behavior

Each part renders and styles the native element named above. The API reference states the exact React or inherited prop base, including whether `ref` is accepted, every omitted native prop, and every component-applied default. Any native prop not named in `Omit` remains accepted, including standard ARIA/data attributes and event handlers. `sx` is composed last.

Wrapping label text names each native switch. When several switches answer one
question, use a `fieldset` and `legend` to expose the relationship. Native
checked state, validation, reset, and submission remain browser-owned.

## API reference

### Switch

`SwitchProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"input">, "className" | "role" | "style" | "type">`. The props below complete `SwitchProps`.

- `controlSize` — `"sm" | "md"`. Default: `'md'`.
- `sx` — `stylex.StyleXStyles`.
