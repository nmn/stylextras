## Anatomy

- `CopyToClipboardButton` — Client clipboard action composed from `Button`.

## Accessibility and browser behavior

The control keeps its accessible action `label` stable, announces localized
success or failure through a text-only polite status, and invokes `onError`
when resolving the value or writing to the Clipboard API fails. Visual popover
feedback is hidden from the accessibility tree to avoid duplicate announcements.
`feedback="none"` suppresses only that visual popover.

## API reference

### CopyToClipboardButton

`CopyToClipboardButtonProps`

- `value` — `string | (() => string)`. Required and resolved when clicked.
- `icon` — `React.ReactNode`. Decorative icon rendered before a copy succeeds.
- `copiedIcon` — `React.ReactNode`. Decorative replacement icon rendered during the copied state.
- `successAnnouncement` — `string`. Polite live-region message announced after a successful copy. Default: `'Copied to clipboard'`.
- `errorAnnouncement` — `string`. Assertive live-region message announced when copying fails. Default: `'Copy failed'`.
- `copiedLabel` — Deprecated alias used as the default success announcement during the beta migration.
- `copiedText` — `React.ReactNode`. Optional visible feedback content for the successful copied state.
- `feedback` — `'popover' | 'none'`. Enables or suppresses the visible copied-feedback popover. Default: `'popover'`.
- `label` — `string`. Stable accessible name for the copy button in every feedback state. Default: `'Copy to clipboard'`.
- `resetAfterMs` — `number`. Milliseconds before copied feedback returns to its idle state. Default: `1500`.
- `onCopy` — `(value: string) => void`. Called with the resolved copied text after clipboard writing succeeds.
- `onError` — `(error: unknown) => void`. Called with the clipboard error after failure feedback is announced.
- `size` — Accessible `ButtonSize`. Controls visual dimensions and, for interactive components, the target size. Default: `'icon'`; icon sizes require the stable `label` supplied by this component.
- `sx` — `stylex.StyleXStyles`, composed after the built-in button and feedback styles.
- `type` — Native button type. Sets the underlying element's native control type. Default: `'button'`.
- `variant` — `ButtonVariant`. Selects the built-in visual treatment. Default: `'ghost'`.
