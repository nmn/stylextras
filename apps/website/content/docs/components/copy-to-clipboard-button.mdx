## Anatomy

- `CopyToClipboardButton` — Client clipboard action composed from `Button`.

## Accessibility and browser behavior

The control keeps its accessible action `label` stable, announces localized
success or failure through a text-only polite status, and invokes `onError`
when resolving the value or writing to the Clipboard API fails. Visual popover
feedback is hidden from the accessibility tree to avoid duplicate announcements.
`feedback="none"` suppresses only that visual popover.

## API reference

### CopyToClipboardButton

`CopyToClipboardButtonProps`

- `value` — `string | (() => string)`. Required and resolved when clicked.
- `icon` — `React.ReactNode`.
- `copiedIcon` — `React.ReactNode`.
- `successAnnouncement` — `string`. Default: `'Copied to clipboard'`.
- `errorAnnouncement` — `string`. Default: `'Copy failed'`.
- `copiedLabel` — Deprecated alias used as the default success announcement during the beta migration.
- `copiedText` — `React.ReactNode`.
- `feedback` — `'popover' | 'none'`. Default: `'popover'`.
- `label` — `string`. Default: `'Copy to clipboard'`.
- `resetAfterMs` — `number`. Default: `1500`.
- `onCopy` — `(value: string) => void`.
- `onError` — `(error: unknown) => void`.
- `size`, `variant`, and `sx` — The corresponding accessible `Button` props.
