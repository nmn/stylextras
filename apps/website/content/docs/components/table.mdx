## Anatomy

- `Table` — Styled `<table>`.
- `TableBody` — Styled `<tbody>`.
- `TableCaption` — Styled `<caption>`.
- `TableCell` — Styled `<td>`.
- `TableFooter` — Styled `<tfoot>`.
- `TableHead` — Styled `<th>`.
- `TableHeader` — Styled `<thead>`.
- `TableRow` — Styled `<tr>`.
- `TableScrollArea` — Opt-in focusable overflow wrapper.

## Accessibility and browser behavior

Each part renders and styles the native element named above. The API reference states the exact React or inherited prop base, including whether `ref` is accepted, every omitted native prop, and every component-applied default. Any native prop not named in `Omit` remains accepted, including standard ARIA/data attributes and event handlers. `sx` is composed last.

Use a caption to name or describe the table and preserve native row and column
headers. `TableScrollArea` is neutral by default. Pass `tabIndex={0}` only when
keyboard users need to scroll the wrapper itself, and then provide
`aria-label` or `aria-labelledby`.

### TableScrollArea

- `tabIndex` — `-1 | 0`. No default.
- `aria-label` or `aria-labelledby` — Required when `tabIndex={0}`.
- `sx` — `stylex.StyleXStyles`.
