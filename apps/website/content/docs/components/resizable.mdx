## Accessibility and browser behavior

Each part renders and styles the native element named above. The API reference states the exact React or inherited prop base, including whether `ref` is accepted, every omitted native prop, and every component-applied default. Any native prop not named in `Omit` remains accepted, including standard ARIA/data attributes and event handlers. `sx` is composed last.

This component uses a focused client controller for composite state and keyboard interaction while retaining native elements for focus and form semantics where possible. Its behavior comes from the component controller rather than a browser-feature polyfill.

The separator has a density-independent pointer target around its thin visual
rule, exposes its finite normalized bounds and current value, and reverses
horizontal Arrow behavior in RTL. It requires an accessible name and
`aria-controls` referencing the affected panel IDs. Arrow keys adjust the split,
Shift+Arrow uses a larger step, and Home/End move to the normalized bounds.

## API reference

### Resizable

`ResizableProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "defaultValue" | "style">`. The props below complete `ResizableProps`.

- `defaultValue` — `number`. Initial value for uncontrolled usage. Default: `50`.
- `direction` — `"vertical" | "horizontal"`. Controls the pane layout and resize-key axis. Default: `'horizontal'`.
- `max` — `number`. Inclusive upper bound. Default: `90`.
- `min` — `number`. Inclusive lower bound. Default: `10`.
- `onValueChange` — `(value: number) => void`. Called when user interaction requests a new numeric value.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
- `value` — `number`. Current controlled numeric value; pair it with `onValueChange`.

### ResizableHandle

`ResizableHandleProps`

Complete native/inherited prop base omits the component-owned separator role,
orientation, numeric value attributes, value text, accessible-name fields, and
`aria-controls`, then adds back the required name and controls relationship.

- `aria-label` or `aria-labelledby` — Required accessible separator name.
- `aria-controls` — `string`. Required ID reference for the affected panels.
- `getValueText` — `(value: number) => string`. Produces localized `aria-valuetext` for the current split percentage. Default: percentage text such as `"38%"`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
- `tabIndex` — `ResizableHandleProps["tabIndex"]`. Keeps the separator handle reachable for keyboard resizing. Default: `0`.
