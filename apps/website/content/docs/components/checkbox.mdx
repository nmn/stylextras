## Accessibility and browser behavior

Each part renders and styles the native element named above. The API reference states the exact React or inherited prop base, including whether `ref` is accepted, every omitted native prop, and every component-applied default. Any native prop not named in `Omit` remains accepted, including standard ARIA/data attributes and event handlers. `sx` is composed last.

Wrapping label text associates each native checkbox. When several checkboxes
answer one question, group them in a `fieldset` with a visible `legend`, as in
the example. Native keyboard, validation, reset, and submission behavior remain
unchanged.

## API reference

### Checkbox

`CheckboxProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"input">, "className" | "style" | "type">`. The props below complete `CheckboxProps`.

- `controlSize` — `"sm" | "md"`. Controls the native control dimensions and touch target. Default: `'md'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
