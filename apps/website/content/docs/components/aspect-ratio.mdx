## API reference

### AspectRatio

`AspectRatioProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "style">`. The props below complete `AspectRatioProps`.

- `ratio` — `AspectRatioValue`. Controls the rendered width-to-height proportion. Default: `"video"`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
