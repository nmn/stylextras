## Anatomy

- `Drawer` — Styled `<dialog>`.
- `DrawerBody` — Styled `<div>`.
- `DrawerClose` — Styled `<button>`.
- `DrawerFooter` — Styled `<div>`.
- `DrawerHeader` — Styled `<div>`.
- `DrawerTrigger` — Styled `<button>`.
- `DialogCommandBridge` — Optional feature-detected invoker-command fallback.

## Accessibility and browser behavior

Each part renders and styles the native element named above. The API reference states the exact React or inherited prop base, including whether `ref` is accepted, every omitted native prop, and every component-applied default. Any native prop not named in `Omit` remains accepted, including standard ARIA/data attributes and event handlers. `sx` is composed last.

Give the native dialog a heading relationship and associate concise descriptive
copy when it helps explain the task. The example installs
`DialogCommandBridge`, which feature-detects native invoker commands before
loading its fallback. `LazyDrawer` installs the same fallback internally.

## API reference

### Drawer

`DrawerProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"dialog">, "aria-label" | "aria-labelledby" | "className" | "style">` plus one required accessible name.

- `aria-label` or `aria-labelledby` — Required accessible dialog name.
- `side` — `DrawerSide`. Selects the edge from which the surface is positioned. Default: `'bottom'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### DrawerBody

`DrawerBodyProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "style">`. The props below complete `DrawerBodyProps`.

- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.

### DrawerClose

`DrawerCloseProps`

Complete native/inherited prop base: `DrawerTriggerProps`. The props below complete `DrawerCloseProps`.

- `size` — `ButtonSize`. Controls visual dimensions and, for interactive components, the target size. Default: `'md'`.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
- `target` — `string`. ID of the element controlled by this trigger. Required.
- `type` — `DrawerCloseProps["type"]`. Sets the underlying element's native control type. Default: `'button'`.
- `variant` — `ButtonVariant`. Selects the built-in visual treatment. Default: `'outline'`.
