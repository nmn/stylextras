### Example code

```tsx
'use client';

import { ButtonGroup } from '../button-group';
import { DialogCommandBridge } from '../dialog/client';
import {
  Drawer,
  DrawerBody,
  DrawerClose,
  DrawerFooter,
  DrawerHeader,
  DrawerTrigger,
  type DrawerSide,
} from './index';

function PageSettingsDrawer({ id, side }: { id: string; side: DrawerSide }) {
  return (
    <Drawer
      id={id}
      side={side}
      aria-labelledby={`${id}-title`}
      aria-describedby={`${id}-description`}
    >
      <DrawerHeader>
        <h2 id={`${id}-title`}>Page settings</h2>
      </DrawerHeader>
      <DrawerBody>
        <p id={`${id}-description`}>
          Change the settings for this page.
        </p>
      </DrawerBody>
      <DrawerFooter>
        <ButtonGroup variant="actions" aria-label="Page settings actions">
          <DrawerClose target={id}>Cancel</DrawerClose>
          <DrawerClose target={id} variant="primary">
            Done
          </DrawerClose>
        </ButtonGroup>
      </DrawerFooter>
      <DialogCommandBridge target={id} />
    </Drawer>
  );
}

export default function Example() {
  return (
    <>
      <DrawerTrigger target="bottom-page-drawer">
        Open bottom drawer
      </DrawerTrigger>
      <PageSettingsDrawer id="bottom-page-drawer" side="bottom" />

      <DrawerTrigger target="top-page-drawer">Open top drawer</DrawerTrigger>
      <PageSettingsDrawer id="top-page-drawer" side="top" />
    </>
  );
}
```

## Anatomy

- `Drawer` — Styled `<dialog>`.
- `DrawerBody` — Styled `<div>`.
- `DrawerClose` — Styled `<button>`.
- `DrawerFooter` — Styled `<div>`.
- `DrawerHeader` — Styled `<div>`.
- `DrawerTrigger` — Styled `<button>`.
- `DialogCommandBridge` — Optional feature-detected invoker-command fallback.

## Accessibility and browser behavior

Each part renders and styles the native element named above. The API reference states the exact React or inherited prop base, including whether `ref` is accepted, every omitted native prop, and every component-applied default. Any native prop not named in `Omit` remains accepted, including standard ARIA/data attributes and event handlers. `sx` is composed last.

Give the native dialog a heading relationship and associate concise descriptive
copy when it helps explain the task. The example installs
`DialogCommandBridge`, which feature-detects native invoker commands before
loading its fallback. `LazyDrawer` installs the same fallback internally.

## API reference

### Drawer

`DrawerProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"dialog">, "aria-label" | "aria-labelledby" | "className" | "style">` plus one required accessible name.

- `aria-label` or `aria-labelledby` — Required accessible dialog name.
- `side` — `DrawerSide`. Default: `'bottom'`.
- `sx` — `stylex.StyleXStyles`.

### DrawerBody

`DrawerBodyProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "style">`. The props below complete `DrawerBodyProps`.

- `sx` — `stylex.StyleXStyles`.

### DrawerClose

`DrawerCloseProps`

Complete native/inherited prop base: `DrawerTriggerProps`. The props below complete `DrawerCloseProps`.

- `size` — `ButtonSize`. Default: `'md'`.
- `sx` — `stylex.StyleXStyles`.
- `target` — `string`. Required.
- `type` — `DrawerCloseProps["type"]`. Default: `'button'`.
- `variant` — `ButtonVariant`. Default: `'outline'`.

### DrawerFooter

`DrawerFooterProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "style">`. The props below complete `DrawerFooterProps`.

- `sx` — `stylex.StyleXStyles`.

### DrawerHeader

`DrawerHeaderProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "style">`. The props below complete `DrawerHeaderProps`.

- `sx` — `stylex.StyleXStyles`.

### DrawerTrigger

`DrawerTriggerProps`

Complete native/inherited prop base: `ButtonProps`. The props below complete `DrawerTriggerProps`.

- `size` — `ButtonSize`. Default: `'md'`.

- `target` — `string`. Required.
- `type` — `DrawerTriggerProps["type"]`. Default: `'button'`.
- `variant` — `ButtonVariant`. Default: `'primary'`.
