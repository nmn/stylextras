                  Overview
                </SidebarMenuLink>
              </SidebarMenuItem>
              <SidebarMenuItem>
                <SidebarMenuLink href="/workspace/projects">Projects</SidebarMenuLink>
              </SidebarMenuItem>
              <SidebarMenuItem>
                <SidebarMenuLink href="/workspace/team">Team</SidebarMenuLink>
              </SidebarMenuItem>
            </SidebarMenu>
          </SidebarGroup>
          <SidebarGroup>
            <SidebarGroupLabel>Manage</SidebarGroupLabel>
            <SidebarMenu>
              <SidebarMenuItem>
                <SidebarMenuLink href="/workspace/settings">Settings</SidebarMenuLink>
              </SidebarMenuItem>
            </SidebarMenu>
          </SidebarGroup>
        </SidebarNavigation>
      </SidebarContent>
      <SidebarFooter>Signed in as Ada</SidebarFooter>

## Anatomy

- `Sidebar` — Styled `<aside>`.
- `SidebarContent` — Styled `<div>`.
- `SidebarFooter` — Styled `<div>`.
- `SidebarGroup` — Styled `<div>`.
- `SidebarGroupLabel` — Styled `<h3>`.
- `SidebarHeader` — Styled `<div>`.
- `SidebarMenu` — Styled `<ul role="list">`.
- `SidebarMenuButton` — Styled `<button>`.
- `SidebarMenuItem` — Styled `<li>`.
- `SidebarMenuLink` — Styled native `<a>` for navigation destinations.
- `SidebarNavigation` — Named `<nav>` landmark.
- `SidebarTrigger` — Styled `<button>`.

## Accessibility and browser behavior

Each part renders and styles the native element named above. The API reference states the exact React or inherited prop base, including whether `ref` is accepted, every omitted native prop, and every component-applied default. Any native prop not named in `Omit` remains accepted, including standard ARIA/data attributes and event handlers. `sx` is composed last.

Name the sidebar region and wrap navigation links in a separately named
`SidebarNavigation`. `SidebarMenu` explicitly preserves list semantics when its
markers are removed. Popover mode uses the native Popover API; unsupported
presentation features do not change the underlying links or landmark structure.

## API reference

### Sidebar

`SidebarProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"aside">, "aria-label" | "aria-labelledby" | "className" | "popover" | "style">` plus one required accessible name.

- `aria-label` or `aria-labelledby` — Required accessible region name.
- `mode` — `"popover" | "inline"`. Default: `'inline'`.
- `sx` — `stylex.StyleXStyles`.

### SidebarContent

`SidebarContentProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "style">`. The props below complete `SidebarContentProps`.

- `sx` — `stylex.StyleXStyles`.

### SidebarFooter

`SidebarFooterProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "style">`. The props below complete `SidebarFooterProps`.

- `sx` — `stylex.StyleXStyles`.

### SidebarGroup

`SidebarGroupProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "style">`. The props below complete `SidebarGroupProps`.

- `sx` — `stylex.StyleXStyles`.

### SidebarGroupLabel

`SidebarGroupLabelProps`

Complete native/inherited prop base is the selected polymorphic heading element.

- `as` — React element type. Default: `h3`; choose the heading level that fits the page outline.
- `sx` — `stylex.StyleXStyles`.

### SidebarHeader

`SidebarHeaderProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"div">, "className" | "style">`. The props below complete `SidebarHeaderProps`.

### SidebarMenuButton

`SidebarMenuButtonProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"button">, "className" | "style">`. The props below complete `SidebarMenuButtonProps`.

### SidebarMenuItem

`SidebarMenuItemProps`

Complete native/inherited prop base: `Omit<React.ComponentPropsWithRef<"li">, "className" | "style">`. The props below complete `SidebarMenuItemProps`.

- `sx` — `stylex.StyleXStyles`.

### SidebarTrigger

`SidebarTriggerProps`

Complete native/inherited prop base: `Omit<ButtonProps, "popoverTarget" | "popoverTargetAction">`. The props below complete `SidebarTriggerProps`.

- `aria-label` — `string`. Required unless `aria-labelledby` is provided.
- `aria-labelledby` — `string`. Required unless `aria-label` is provided.
- `sx` — `stylex.StyleXStyles`.
- `target` — `string`. Required.
- `type` — `SidebarTriggerProps["type"]`. Default: `'button'`.
- `variant` — `ButtonVariant`. Default: `'outline'`.

### SidebarNavigation

- `aria-label` or `aria-labelledby` — Required accessible navigation-landmark name.
- `sx` — `stylex.StyleXStyles`.
