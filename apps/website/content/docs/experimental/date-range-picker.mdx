## Accessibility and browser behavior

Each part renders and styles the native element named above. The API reference states the exact React or inherited prop base, including whether `ref` is accepted, every omitted native prop, and every component-applied default. Any native prop not named in `Omit` remains accepted, including standard ARIA/data attributes and event handlers. `sx` is composed last.

`DateRangePicker` enhances the zero-JavaScript `RangeCalendar` composition with
cross-field range-order validation. It uses the end input's native constraint
validation and `setCustomValidity`, exposes `aria-invalid` only after the user
interacts, associates a localizable error with `aria-errormessage`, preserves
caller descriptions, and clears interaction state on form reset. Native entry,
external form association, and submission remain intact.

## API reference

### DateRangePicker

`DateRangePickerProps`

Complete native/inherited prop base: `RangeCalendarProps`. The props below complete `DateRangePickerProps`.

- `legend` — `ReactNode`. Visible accessible label for the grouped controls. Required.
- `startLabel`, `endLabel` — `ReactNode`.
- `startName`, `endName` — `string`.
- `startDefaultValue`, `endDefaultValue` — `string`.
- `startProps`, `endProps` — Per-field props, including refs and event handlers, merged with the wrapper's validation behavior.
- `invalidRangeMessage` — Plain localized range-order error. Default: `'End date must be on or after start date.'`.
- `min`, `max` — ISO date strings.
- `sx` — `stylex.StyleXStyles`. Theme-aware local overrides composed after the built-in styles.
