## Documentation preset

The site shell and component galleries use `stylePresets.docs`. Its existing
color, typography, spacing, radius, stroke, elevation, blur, and motion themes
form the documentation design system. Package components consume those token
sets directly.

```tsx
import * as stylex from "@stylexjs/stylex";
import { stylePresetThemes } from "@stylextras/ui/style-presets";

export function DocsTheme({ children }) {
  return (
    <section {...stylex.props(...stylePresetThemes("docs"))}>
      {children}
    </section>
  );
}
```

Component galleries and reference fixtures are explicitly nested under the
same preset so they remain isolated from a consuming page’s surrounding theme.

```tsx
import * as stylex from "@stylexjs/stylex";
import { stylePresetThemes } from "@stylextras/ui/style-presets";

export function ComponentGalleryTheme({ children }) {
  return (
    <section {...stylex.props(...stylePresetThemes("docs"))}>
      {children}
    </section>
  );
}
```

## Composition

Color, spacing, radius, stroke, typography, elevation, blur, and motion remain
independent variable groups. Components reference those variables directly, so
a preset changes their built-in styling without broad `sx` replacement rules.
Use `sx` only for isolated website-specific exceptions.
