## Documentation preset

The website starts with `docsPresetThemes`. Use the palette button in the
header to open its anchored Theme dialog. The selected preset, appearance, and
all eight variable groups apply to the entire site: the shell, navigation,
search, documentation content, reference gallery, and every live component
example. Examples deliberately inherit that global selection instead of
creating isolated theme boundaries.

The documentation preset coordinates color, typography, spacing, radius,
stroke, elevation, blur, and motion. Package components consume those token
sets directly.

```tsx
import * as stylex from "@stylexjs/stylex";
import { docsPresetThemes } from "@stylextras/ui/style-presets/docs";

export function DocsTheme({ children }) {
  return (
    <section {...stylex.props(...docsPresetThemes)}>
      {children}
    </section>
  );
}
```

## Composition

Color, spacing, radius, stroke, typography, elevation, blur, and motion remain
independent variable groups. Components reference those variables directly, so
a preset changes their built-in styling without broad `sx` replacement rules.
Use `sx` only for isolated website-specific exceptions.

Every named theme and preset has a direct export such as
`@stylextras/ui/color-themes/blue` or `@stylextras/ui/style-presets/aurora`.
Those subpaths keep unrelated theme CSS out of the application. Family and
preset root imports are intentionally full catalogs for runtime theme pickers.
Accent color files are compact overrides: compose `neutralTheme` first when
using one directly. Named presets already include that base reset, followed by
their selected accent and the other seven axes.

## Surface layering and concentric radii

Every color theme defines the same surface progression: page background,
subtle container, raised card/control, then top-layer popover. In dark mode,
each nested surface becomes lighter than its container; in light mode it gains
equivalent separation without turning cards gray or muddy.

Radius themes override the shared base radius and let the token scale derive
smaller and larger values. Components use the smaller tokens for controls nested
inside cards and popovers, keeping adjacent corners visually concentric across
every preset. An `sx` value still composes last when a product needs a local
exception.
